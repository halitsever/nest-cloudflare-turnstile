# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| 0.0.x   | No        |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub's advisory form](https://github.com/halitsever/nest-cloudflare-turnstile/security/advisories/new) instead.

Include the package version, your NestJS and Node.js versions, and the steps that reproduce the problem. Leave real secret keys out of the report.
